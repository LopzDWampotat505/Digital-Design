\section{Introduction} %Breve introducción al tema del reporte
The analysis and design of digital circuits is based on the representation and manipulation of Boolean functions through logic gates. These gates allow the implementation of fundamental operations in digital electronics, and when combined, enable the construction of complex systems. Therefore, it is essential to understand both the algebraic expressions and their translation into schematics, as well as the reverse process of generating schematics from Boolean functions.
The main objective of this laboratory practice was to establish the bidirectional relationship between Boolean functions and logic circuits: deriving expressions from schematics and, conversely, constructing schematics from given functions. Additionally, modern digital design tools, such as Multisim simulation and VHDL programming using the EDA Playground platform, were incorporated, allowing for both experimental and virtual validation of circuit functionality.
\begin{itemize}
  \item NAND, output is false only if all inputs are true.
  \item NOR, output is true only if any input is false.
  \item XOR, outputs true if inputs are different.
  \item XNOR, outputs true if inputs are the same.
\end{itemize}\cite{unacademy_logic_gates}
It's critical to comprehend not only how these compounded gates operate but also the various ways in which they can be connected within a circuit.  Additionally, we can investigate the plethora of possibilities in the field of digital logic by experimenting with various compounded gate configurations.
\section{Objectives} %Objetivos de la práctica
The objectives of this lab are:
\begin{itemize}
    \item Obtain Boolean functions from schematics.
    \item Obtain schematics from Boolean functions.
    \item Program and simulate Boolean functions using VHDL.
\end{itemize}
For the purpose of this lab, it is important to know about the components used, in the first place, "logic gates are defined as simple digital circuits that take one or more binary inputs and produce a binary output"\cite{HARRIS20221}.
On the other hand, boolean funtions consists of a number of Boolean variables joined by the Boolean connectives, like AND and OR. \cite{HOLDSWORTH200228}
Similary to the previous lab, the software utilized in the experiment is VHDL (Hardware Description Language), which is a language that describes the behavior of electronic circuits, most commonly digital circuits. \cite{IntelVHDLDef}
For this experiment, it is fundamental to explain the procedure to convert a schematic into a boolean function, in this case, one must know how to write a truth table, and construct the canonic form of the function.
\\To understand this, we must define the elements of a electronic schematic. For most circuits, a photograph or realistic drawing showing actual components and their interconnections would be far too complex to be of value in replicating the circuit. A schematic symbol is a simplified representation of a real-world component. A schematic diagram shows such representations of real-world components and a simplified “map” of how they are connected together.\cite{VARTERESIAN20021}
\\Once a schematic is created or obtained, the truth table must be generated, since the truth table is defined as a canonical representation of a Boolean function that exhaustively enumerates every truth assignment and its corresponding function value. \cite{JIANG2009299}
\\And it is through this truth table that a canonic function can be obtained, which refers to a Boolean function that is expressed either as a sum of minterms or as a product of maxterms. It represents the standard form of a Boolean function that can be manipulated to simplify its expression. \cite{HOLDSWORTH200243}

\section{Analysis of Results}

\subsection{Detailed Analysis of the Figure and Determination of the Logic Function}

\subsubsection{Gate Identification and Description (According to Figure 1)}
By carefully examining the provided figure, each logic block was identified and how they interact to form the final output was established. The gates are described as follows:
\begin{itemize}
    \item \textbf{Top left gate: NAND with inputs A and B.}
    $$N = (A \cdot B)'$$
    This gate produces a high output for all input combinations, except when A and B are both 1, where the output is 0. It plays a key role in controlling the upper right section of the circuit.
    \item \textbf{Middle left gate: XNOR with inputs B and C, with a negation bubble at the output.}
    $$M = B \text{ XNOR } C = (B \oplus C)'$$
    The output is high when B and C are equal and low when they differ. The bubble indicates that the XOR operation is reversed, producing XNOR behavior.
    \item \textbf{Lower left gate: XOR with inputs C and D, with no negation on the output.}
    $$X = C \oplus D$$
    The output is high only when C and D are different, introducing variability depending on the relationship between the two inputs.
    \item \textbf{Upper center-right gate: NOR with N and M inputs.}
    $$T = (N + M)'$$
    The output T will be high only when both inputs N and M are low, acting as a detector for conditions where the previous signals are zero and affecting the final output.
    \item \textbf{Bottom center-right gate: OR with inputs M and X.}
    $$B_2 = M + X$$
    Output $B_2$ will be high if at least one of the inputs is 1, ensuring that partial conditions detected by M or X activate the signal.
    \item \textbf{Final gate (right): NAND with inputs T and $B_2$, producing output Y.}
    $$F_1 = (T \cdot B_2)'$$
    The final output is high in most combinations and only goes low when T and $B_2$ are simultaneously high, representing the critical condition of the circuit.
\end{itemize}
Therefore, the final output is:
$$Y = (((A \cdot B)' + (B \oplus C)')' \cdot ((B \oplus C)' + (C \oplus D)))'$$

\subsubsection{Compound Boolean Expression and Step-by-Step Analysis of the Output}
Replacing the above definitions in the final output:
$$Y = (T \cdot B_2)'$$

\paragraph{Conditions for Y = 0}
For the Y output to be 0, both inputs of the final NAND must be high:
$$T = 1 \text{ and } B_2 = 1$$
\begin{itemize}
    \item \textbf{Analyzing T:}
    $$T = (N + M)'$$
    For $T = 1$, the inner sum must be 0:
    $$N + M = 0 \Rightarrow N = 0 \text{ and } M = 0$$
    \item \textbf{Analyzing $B_2$:}
    $$B_2 = M + X$$
    For $B_2 = 1$, at least one input must be high:
    $$M + X = 1 \Rightarrow X = 1 \text{ (since } M = 0 \text{)}$$
\end{itemize}

\paragraph{Translation to Input Combinations}
\begin{itemize}
    \item $N = (A \cdot B)' = 0 \rightarrow A \cdot B = 1 \rightarrow A = 1 \text{ and } B = 1$
    \item $M = (B \oplus C)' = 0 \rightarrow B \oplus C = 1 \rightarrow B \text{ and } C \text{ are different, with } B = 1 \rightarrow C = 0$
    \item $X = C \oplus D = 1 \rightarrow C \neq D, \text{ with } C = 0 \rightarrow D = 1$
\end{itemize}
The only combination that satisfies all the conditions is:
$$(A,B,C,D) = (1,1,0,1)$$
Thus, $Y = A \cdot B \cdot C' \cdot D$, and its minterms representation is decimal row 13 (binary 1101). In maxterms product:
$$Y = \prod M(13)$$

\subsubsection{Verification Using Truth Tables and Simulation}
\begin{itemize}
    \item Table 1 confirms that the output is 1 for 15 of the 16 possible input combinations, perfectly matching the algebraic analysis.
    \item The only row with $Y = 0$ corresponds exactly to the combination $(1, 1, 0, 1)$, as deduced step by step.
    \item Simulation in Multisim and EDA Playground, represented in waveforms, shows that the output remains high for most input vectors and presents a single low pulse for the indicated combination, verifying the consistency between the truth table, the Boolean expression, and the practical simulation.
\end{itemize}

\subsection{Detailed Analysis of the Function and Determination of the Logic}

\subsubsection{Identification and Description of the Gates (According to the Provided Function)}
The proposed function is:
$$F(A,B,C,D) = (B' \cdot D) \cdot (A \oplus B) + (A \cdot C)$$
Analyzing each logic block:
\begin{itemize}
    \item \textbf{NOT gate at B:} $B'$
    Inverts the value of input B, enabling conditions dependent on B being 0.
    \item \textbf{AND gate between B' and D:} $E = B' \cdot D$
    The output E will be high when $B=0$ and $D=1$.
    \item \textbf{XOR gate between A and B:} $X = A \oplus B$
    This output is high only when A and B are different.
    \item \textbf{AND gate between E and X:} $T = (B' \cdot D) \cdot (A \oplus B)$
    This block detects the specific condition: $B=0$, $D=1$, and $A \neq B$.
    \item \textbf{AND gate between A and C:} $U = A \cdot C$
    Activates the output when $A=1$ and $C=1$, regardless of B or D.
    \item \textbf{Final OR gate between T and U:} $Y = T + U$
    The output will be high if either of the two conditions is met: the combination of the first branch (T) or the direct condition $A \cdot C$.
\end{itemize}
Thus, the output is described as:
$$Y = (B' \cdot D) \cdot (A \oplus B) + (A \cdot C)$$
Once the analysis of the function was completed, the diagram that reflects its logical behavior was developed, which facilitated the interpretation and verification of the obtained result.

\subsubsection{Compound Boolean Expression and Step-by-Step Analysis of the Output}
\paragraph{Conditions for Output = 1}
The output is 1 when at least one branch of the OR is 1:
\begin{itemize}
    \item \textbf{Branch 1 (T):}
    $$(B' \cdot D) \cdot (A \oplus B) = 1$$
    This requires simultaneously:
    \begin{itemize}
        \item $B = 0$ and $D = 1$
        \item $A \neq B$ (i.e., $A=1$)
    \end{itemize}
    Therefore, Branch 1 is activated with: $(A,B,C,D) = (1,0,*,1)$ (C is irrelevant in this branch).
    \item \textbf{Branch 2 (U):}
    $$A \cdot C = 1$$
    This requires $A=1$ and $C=1$, regardless of B and D.
\end{itemize}

\paragraph{Translation to Input Combinations}
\begin{itemize}
    \item From Branch 1, we obtain minterms: $(1,0,0,1)$ and $(1,0,1,1) \rightarrow \text{decimals } 9 \text{ and } 11$.
    \item From Branch 2, we obtain minterms:
    \begin{itemize}
        \item $(1,*,1,0) \rightarrow (1,0,1,0) \text{ and } (1,1,1,0) \rightarrow \text{decimals } 10 \text{ and } 14$
        \item $(1,*,1,1) \rightarrow (1,0,1,1) \text{ and } (1,1,1,1) \rightarrow \text{decimals } 11 \text{ and } 15$
    \end{itemize}
\end{itemize}
Joining results:
$$Y = \sum m(9, 10, 11, 14, 15)$$

\subsubsection{Verification via Truth Table and Simulation}
\begin{itemize}
    \item Table 2 confirms that the output is 1 for 5 of the 16 possible input combinations, perfectly matching the algebraic analysis.
    \item Simulation in Multisim and EDA Playground, represented in waveforms, shows that the output remains high for most input vectors and presents a single low pulse for the indicated combination, verifying the consistency between the truth table, the Boolean expression, and the practical simulation.
\end{itemize}
This detailed analysis confirms that the circuit design correctly implements the intended logic function. The methodology (gate identification, partial output analysis, and verification of the conditions for Y = 0) ensures accurate results and provides a complete understanding of the role of each block within the circuit.

In this way, the practice not only enabled experimental validation of theoretical principles but also reinforced the understanding of programming and simulation of Boolean functions in digital environments.
